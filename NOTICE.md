## CircleRun-Bullet

The training framework uses code from [FSRL](https://github.com/liuzuxin/fsrl) with the MIT license in `CircleRun-Bullet/fsrl/LICENSE`.
The simulation environment uses [Bullet-Safety-Gym](https://github.com/liuzuxin/Bullet-Safety-Gym) with the MIT license in `CircleRun-Bullet/Bullet-Safety-Gym/LICENSE`.

The GradS comparison algorithms use `CircleRun-Bullet/fsrl/policy/lagrangian_base.py`. 
[The GradS paper](https://proceedings.mlr.press/v242/yao24a.html) describes the method.

Each MIT license requires its copyright notice and permission text with copies or substantial portions of the code.

## CircleRun-Mjx

This folder contains the circle experiments for JAX and MJX. 
The design uses ideas from [Safety Gym](https://github.com/openai/safety-gym), [Safety-Gymnasium](https://github.com/PKU-Alignment/safety-gymnasium), [Bullet-Safety-Gym](https://github.com/SvenGronauer/Bullet-Safety-Gym), and [GradS](https://proceedings.mlr.press/v242/yao24a.html).
